# TagsView 多标签页导航 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standard, route-integrated TagsView with safe keep-alive caching.

**Architecture:** Pinia owns visited tags and cache names; the router registers only navigable pages after successful navigation; the layout renders the tag component and the cached route view.

**Tech Stack:** Vue 3, Vue Router 4, Pinia 4, Element Plus, Node test runner.

## Global Constraints

- Preserve the pre-existing uncommitted stage-B edits.
- Do not register login, 404, redirected, hidden, or unmatched routes.
- Cache only pages marked `meta.cache` and identified by real component names.
- `/dashboard` is the non-removable affixed fallback.
