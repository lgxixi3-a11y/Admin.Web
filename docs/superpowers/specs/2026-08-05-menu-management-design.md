# 菜单管理页面优化设计（阶段 E）

## 目标

优化 `src/views/system/menu/index.vue` 的菜单树浏览体验：增加纯客户端搜索筛选、展开/折叠交互、图标预览、类型徽标和紧凑表格布局。

## 数据与筛选

- 保持 `GET /system/menu/tree` 的原始全量返回数据不变；筛选只影响传给表格的展示树。
- 搜索条件为菜单名称、权限标识、菜单类型和状态，节点须同时满足已填写的条件。
- 递归生成新树：命中节点直接保留；未命中但存在命中后代时保留该节点作为祖先路径；每个保留节点都带有 `children` 数组（空数组不省略）。因此子节点命中时始终可见且树结构可正确渲染。
- 查询按钮提交当前条件；重置按钮清空全部条件。条件变化不会重新请求后端。

## 交互与呈现

- 表格工具栏在页面标题、新增和刷新操作附近提供“展开全部”“折叠全部”。默认保留当前全部展开行为；手动操作通过表格引用调用展开/收起 API。
- 图标列以 Element Plus 图标组件预览已知图标，未知或空图标显示破折号。
- 类型列按目录/菜单/按钮分别以 `primary`、`success`、`warning` 的浅色 `el-tag` 展示。
- 保留现有状态 `DictTag` 与链接式操作按钮；表格使用斑马纹和 `small` 尺寸。低频字段不新增到列表。

## 错误处理与兼容性

- 保留既有加载代次保护和删除逻辑。
- 展开/折叠仅作用于当前过滤后的可见行；表格引用尚未就绪时安全无操作。
- 图标名称无对应组件时不抛出渲染错误。

## 验证

- 新增可独立运行的树筛选单元测试，覆盖：组合条件、命中子节点保留祖先路径、空 `children` 保留、源树不被修改。
- 运行对应 Node 测试、`npm run lint` 和 `npm run build`。
